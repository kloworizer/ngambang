# Ngambang

An edge-docked floating island for Windows — a small orb on any screen edge
that shows ambient progress and unfolds into slips for media, coding and gaming.
Native Rust + Windows composition, targeting 0 % idle CPU and under 12 MB
private working set.

- Specification for the first build: [docs/SPEC.md](docs/SPEC.md)
- Visual mockup: https://claude.ai/artifact/S2ADpcUg2EJqHLpewaD7uZ

Status: design / pre-alpha.
